# 🗺️ Interactive Bible Map – Jacob Journey

This project provides an interactive map of Jacob’s journey (Genesis 28–33) using Streamlit.

## 🚀 Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## ☁️ Deploy on Streamlit Cloud
1. Go to https://share.streamlit.io
2. Click **Create App**
3. Select this repository
4. Entry file: `app.py`

Streamlit Cloud deploys directly from GitHub and auto-updates when you push changes. citeturn312722search0

## 📍 Features
- Interactive map (Folium)
- Jacob path visualization
- Esau direction comparison
- Theological layers
- Modern geography labels

## 📖 Data note
Coordinates are approximate for educational purposes.
